FLIMa Main Page
===============

What is FLIMa?
--------------

FLIMa is an open source :code:`napari` widget for performing Fluorescence Lifetime Imaging Microscopy data analysis. FLIMa supports both Time Domain and Frequency Domain FLIM data and provides per-sample and group based statistical analysis of FLIM data using FLIM Phasor analysis techniques.
